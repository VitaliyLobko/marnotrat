# Марнотрат

Облік витрат монетками: дохід — на рахунок, рахунок — на витрату чи інший рахунок.
PWA без збірки (HTML, CSS, JS-модулі), дані — в IndexedDB на телефоні, копія — файлом JSON.

Локально: `py -m http.server` у цій теці (service worker на 127.0.0.1 не вмикається).
Іконки: `py scripts/make_icons.py`. Іконки Lucide — js/icons-lucide.js (ISC).
